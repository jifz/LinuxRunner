# 用户指南

LinuxRunner 在 iPhone 和 iPad 上运行 ARM64 Linux。

## 快速开始

1. 安装 LinuxRunner IPA
2. 打开应用，选择 **设置 Linux…**
3. 选择发行版（推荐 Debian）
4. 创建 Linux 账户
5. 安装桌面组件（可选）
6. 打开终端或桌面

## 主要功能

- **终端** — 命令行 Linux 环境
- **桌面** — 图形 Linux 桌面（Openbox、LXQt 等）
- **应用程序管理器** — 安装和管理 Linux 软件包
- **文件共享** — 在 Linux 和 iOS 之间传输文件
- **外部显示器** — 通过 USB-C 或 AirPlay 输出桌面

## 设置

- **发行版** — 管理 Linux 环境
- **桌面环境** — 选择和安装桌面
- **图形** — 配置渲染器（软件或 Metal GPU）
- **文件共享** — 管理共享文件夹
- **设备** — 外部显示器和网络设置
- **Linux 用户** — 管理 Linux 账户
