# 文件共享

LinuxRunner 提供 Linux 环境和 iOS 文件之间的文件传输。

## 共享文件夹

每个环境有一个共享文件夹，位于 Linux 中的 `/mnt/LinuxRunnerShared`。当名称可用时，还会创建 `~/Shared` 链接。

使用 **设置 → 文件共享** 管理共享文件夹。你可以：

- **导入文件** — 从 iOS 文件选择文件导入到 Linux 共享文件夹
- **导出文件** — 将 Linux 文件导出到 iOS 文件
- **导出文件夹为 ZIP** — 将整个文件夹打包为 ZIP 导出

## 文件限制

- 导入支持最大 512 MiB 的常规文件
- 保留现有文件名
- 导出目录创建 ZIP；链接和特殊文件被拒绝
- 在导出另一个应用正在编辑的文件之前保存更改

## 在 iOS 文件中访问

在 iOS 文件中：**在我的 iPhone/iPad 上 → LinuxRunner → Shared → <环境名称>**

每个环境有自己的文件夹。文件在 Linux 和 iOS 之间持久存在。
