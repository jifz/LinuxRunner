# 桌面控件

## 查看器控件

| 操作 | 效果 |
| --- | --- |
| 点击 | 触摸模式下的左键单击 |
| 长按 | 右键单击（默认） |
| 捏合 | 缩放桌面 |
| 两指移动 | 缩放时平移，适应时滚动 |
| 键盘按钮 | 显示屏幕键盘和修饰键 |

## 桌面设置

**桌面 → 桌面设置…** 提供：

- **显示 → 适应** — 缩放以适应窗口
- **显示 → 实际大小** — 1:1 缩放
- **显示 → 全屏** — 全屏模式
- **显示 → 分辨率与查看器偏好** — 选择 Linux 分辨率

## 会话管理

- **完成** — 分离查看器，保持桌面运行
- **恢复桌面** — 重新连接到活动会话
- **停止桌面** — 结束桌面和所有应用程序

## 快捷键（硬件键盘）

- **Ctrl-Opt-Cmd-M** — 桌面选项
- **Cmd-F** — 适应视图
- **Cmd-0** — 实际大小
- **Cmd-W** — 关闭查看器
